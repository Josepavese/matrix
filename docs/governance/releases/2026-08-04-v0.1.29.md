This release closes
`issues/closed/2026-08-04-codex-acp-launch-policy-not-applied.md`.
Matrix now resolves governed launch policy through a common provider-policy
adapter registry. The Codex adapter maps the protocol-neutral request to the
canonical provider's supported `CODEX_CONFIG` and `INITIAL_AGENT_MODE`
surfaces, verifies the exact ACP session mode, and fails closed when the
installed provider contract cannot apply the request.
