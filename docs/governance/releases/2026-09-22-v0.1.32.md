## Defects Fixed In This Release

Three defects were found by writing failure-path tests, not by review:

- `internal/logic/frontendevents`: tool-call identity ignored the file path, so
  two calls to the same tool with the same description and different arguments
  hashed to the same id and the trace mis-linked a result to the wrong request.
  Identity now includes the path, results still link through the active call, and
  only identity-bearing fields are hashed so a replayed update keeps its id.
- `internal/providers/sidecarprojection`: an empty `text` or `data` block became
  a real A2A part, so a peer received a message that said nothing while the
  fallback path already dropped empty content. Both paths now agree.
- `internal/logic/filesystem`: `MountVirtualFS` and `UnmountVirtualFS` on a
  manager without a provider dereferenced a nil filesystem and panicked inside a
  run. They now return a classified `ERR_FS_UNAVAILABLE` error.
- `internal/logic/sessionview`: rendering a missing session with no translation
  lookup panicked; the exported renderer now degrades to a readable default.

Two contracts were pinned rather than changed, and are worth naming because they
are security-relevant: the local vault refuses to store values without a master
key and seals them at rest when one is present, and the network provider never
writes an HTTP error body to the destination file.

One test-isolation defect was also fixed: the runtime vault tests were talking to
the operator's real runtime broker because they did not isolate `MATRIX_HOME`.
They now point it at a temporary home.
