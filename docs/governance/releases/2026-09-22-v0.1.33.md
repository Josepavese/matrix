## Defects Fixed In This Release

- `internal/providers/sidecarprojection`: the fallback that guarantees a message
  has at least one part ran before the capsules were projected, so a capsule-only
  turn gained a spurious empty text part beside its data parts.
- `internal/logic/frontendevents`: the tool-call identity fix from v0.1.32 left
  the projection with too little test coverage to mutate; closing that gap is what
  allowed the remaining mutants to be killed.

The new tests pin path extraction (absolute paths only, nested maps and slices,
JSON payloads, prose fallback), operation extraction, the canonical name, kind and
status vocabulary, terminal signals that distinguish a running command from an
exited one, permission decisions, and the ACP per-provider capsule envelope.

## Exemptions Closed

- `cmd/mock-agent` now tests its protocol handshake, malformed parameters, the
  default turn, and the elicitation round trip from the peer side. That is the
  only place the elicitation contract is exercised as a client would see it.
- `cmd/matrix` now tests argument filtering, discovery source parsing, the API key
  extraction order, runtime authorisation, invocation path resolution, and the
  doctor report on a machine with no vault. The runtime authorisation test pins a
  deliberate contract: a runtime with no configured key accepts local requests,
  and one with a key refuses a request that carries none.
