This release closes the oldest open issue in the repository, makes the runtime's
authentication surface reachable, gives `install.sh` the same resilience as
`install.ps1`, and adds the published-release verification the runbook was missing.
It is the first release verified end to end by `scripts/verify_release.sh`.

## What The Release Contains

- **A denied process termination no longer fails a completed run**
  (`a9ef5a4`, closes `issues/2026-08-05-windows-ephemeral-cleanup-terminateprocess-access-denied.md`):
  a bounded, classification-aware retry, a new `process_retention_scope` evidence
  field naming what survived, degraded rather than failed cleanup for a retained
  cached shared client, and a run failure that is preserved for a retained
  run-scoped child or wrapper.
- **The agent's authentication surface is reachable at runtime** (`625e033`):
  `GET /v1/agent-auth?agent=<id>` lists the methods the agent advertises and
  `POST /v1/agent-auth/logout?agent=<id>` revokes; both honour the runtime API key.
  A CLI command cannot serve this, because the daemon owns the agent clients and
  holds the vault (bbolt refuses a second writer).
- **`install.sh` survives a stale GitHub index** (`caa8fdf`): the id-addressed
  fallback, plus `tests/install_sh_asset_test.sh` and a new CI job
  `install-sh-assets` that exercise the fallback deterministically.
- **`matrix agent doctor` reports A2A authentication requirements** (`a89fea8`):
  the schemes a remote card declares, and whether the configured headers plausibly
  satisfy them, with the SDK kept behind the provider boundary. This also fixed a
  latent defect: doctor rebuilt the endpoint from a hand-written field list that
  dropped `Headers`, so header-based credentials were invisible to every check.
- **Install progress goes through an injectable writer** (`e27a597`), so a future
  machine-readable install can keep stdout parseable.
- **Governance and release process**: the first written threat model
  (`fd3c42a`, findings tracked in `issues/2026-09-23-security-findings-from-threat-model.md`),
  a concurrency convention for shared checkouts and machines (`34aef1c`),
  `scripts/verify_release.sh` required by the runbook (`2136082`), and the ACP v2
  migration scoped as an issue (`d093ef1`).
