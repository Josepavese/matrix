## What The Release Contains

- **Agent-returned tool calls are authorized** (`880f898`). `applyToolCalls` executed
  every call an agent returned, and `ExecuteTool` dispatched straight into
  `APM_Install`, `APM_Uninstall` and `Config_Set`. The evidence settled the shape of
  the fix: system tools are advertised in exactly one production place — an `/action`
  turn — and that path executes its own calls, so entitlement is turn-scoped, not
  uniform. A call whose name is outside the published contract, whose arguments lack
  a schema-required field, or whose name the turn never advertised is now refused and
  logged. Two intended behaviour changes: a system tool call on a non-`/action` turn
  is refused instead of executed, and a malformed call no longer reaches a handler
  with empty values.
- **Telegram allow-list enforced** (`7e71bf3`): checked before every dispatch path,
  with an enabled channel and an empty list refusing to start.
- **Config writes confined** (`2485004`): resolved path must be inside the PAL home's
  `configs/`, with absolute, `..` and symlink escapes rejected.
- **Toolchain and lint reproducibility, and the quality gate in CI**: the light gate
  now runs on every push to main, which is how the coverage floors turned out to be
  calibrated on a different Go release than CI built with.

## Verification Of The Fixes

- Telegram: package tests including the mutation proof (removing the gate fails seven
  tests, including the one asserting a stranger's callback was acknowledged).
- Config containment: restoring the previous code fails eight tests, covering an
  absolute path outside, `..` traversal, a symlink and a dangling link pointing
  outside, a shared-prefix sibling, the error message, and the same escape driven end
  to end through a real tool call.
- Tool-call authorization: deleting the turn check fails both turn-scoped tests on the
  side effect — the config file is not written — and deleting the whole gate fails
