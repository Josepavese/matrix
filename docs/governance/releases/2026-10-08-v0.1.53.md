# v0.1.53 — sandbox, capacity, semantic filesystem and collector

All four PAL developments authorized on 2026-10-08 are delivered. Implementation,
physical Linux evidence and platform limits: [PAL ledger](../pal_implementation_2026-10-08.md).
Configuration: [operational guide](../../wiki/PAL-Execution-and-Observability.md).

## Delivered surfaces

- Explicit native OpenCode/MiMo policy contracts and an optional Linux-container
  sandbox on Linux/Windows/macOS hosts, shared by local ACP agents and validators.
  Effective engine settings, guest workspace, persistent state, cancellation and
  refusal of host bridges are checked; native tool policy remains separately
  reported as configured, not attested.
- Native disk/volume/CPU/RAM observations, workspace/CLI/authenticated API, and
  common-router concurrency/disk-reservation admission. Reservations are runtime
  accounting, not physical quotas or provider account balances.
- Selected read-only semantic state through fs.FS, CLI, authenticated HTTP and
  optional rclone mount. Private inputs/configuration are excluded; terminal
  summaries require explicit opt-in.
- Optional bounded OTLP/HTTP JSON operational-log export, retaining the local
  primary sink, with authenticated counters and a strict allowlist. No transcript,
  billing, span or OTLP-metric export is implied.
- Defects exposed by native CI fixed: validator path canonicalization and portable
  traversal rejection, Windows log DACL enforcement, terminal-proof cancellation
  ordering, and a premature JSON-RPC initialization response in the cwd test peer.

## Local installation

Local service upgrade is pending. Three existing MiMo runs were detected before
the upgrade; two were still running at the publication checkpoint. The live
v0.1.52 service is preserved while they execute. Both the guarded updater and
its dependent post-install verifier are live, not merely planned. They require
successful public release verification and no running task before stopping the
service for a coherent backup, installation and restart. This does not certify
that the local upgrade or post-install provider probe has already succeeded.

backup; the existing pre-v0.1.52 vault backup is retained. Final local results
will be recorded only after observation.

## Qualification limits

Physical Linux container, validator, ACP session persistence, FUSE and official
collector probes passed as detailed in the PAL ledger. Native Windows/macOS CI
does not certify physical Docker Desktop/WinFsp/macFUSE/FUSE-T installations.
Those optional drivers have explicit prerequisites and no silent fallback.
Provider policy loading and acknowledged model selection do not attest physical
commercial model identity or billing. New optional global policies are not
enabled merely by installing this release.
