### Local wrapper correction during qualification

The maintainer wrapper originally ran `vault migrate` during its post-copy
smoke. Read-write storage opening scans legacy encryption values even when
schema version 1 is current. The qualification's 180-second timeout expired;
its rollback copy encountered the still-executing smoke's binary inode.
The verified installed binary and unchanged configuration were independently
checked, the service was restarted, and all post-startup checks then passed.
No format change was required by this CLI patch; no provider or user data was
restored/deleted to recover the install.

The repository wrapper now checks only version/home/submission help. It does
not invoke storage/runtime commands during artifact installation. A fixture/spy
regression verifies installation and rerun preserve existing Vault/config bytes.
Runtime checks follow service startup. See the
[closed installer correction](../../../issues/closed/local-installer-vault-smoke.md).
This tooling correction does not change the published v0.1.54 binary/tag.

Private backup and bounded qualification evidence are retained at
`/media/jose/Data/matrix-v0.1.54-preinstall-20261009/`. They include the failed
provider-default attempt as well as successful explicit-model and installed
runtime proofs; no credentials or transcripts are published in this ledger.
