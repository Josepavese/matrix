# Matrix v0.1.58 — authenticated readiness

The diagnostic probe now reads the existing `matrix_api_key` from SSOT and
retrieves the authenticated runtime report through the public governed-header
network capability. Missing backend support or wrong credentials remain
failures; no anonymous retry or weakened ingress authentication. Requests with
governed headers cannot redirect across origins; credential-free fetching
retains its existing behavior. Duplicate CLI setup was removed.

Local Gemini 0.65.0 was installed from the official pinned npm package, using
existing dependencies/cache, and registered through `matrix agent set-binary`
with `--acp`. The real ACP initialize response confirms version 0.65.0 and wire
protocol 1; no model prompt or interactive authentication was submitted.

Regressions cover the authenticated local report, failed authentication,
missing header support, allowed same-origin redirects, and refused cross-origin
redirects without forwarding a request to the other server. PAL includes the
network and runtime-check suites on Linux, macOS and Windows. No storage schema
change or Vault migration.

Final publication and installed strict-readiness evidence follows verification.
