# Matrix v0.1.59 — governed typed run input

Run input now preserves ordered text/image content through the existing neutral
router, session and protocol contracts. Strict JSON rejects unknown/noncanonical
fields, duplicates and extra documents, including custom nested unmarshalling.
PNG/JPEG validation bounds encoded/decoded bytes, aggregate size and dimensions.
Unsupported content never falls back to a successful text-only task.

The input owner defines limits and a canonical payload digest. Request
idempotency includes the complete typed payload and source metadata; replays
perform no capability probe or new dispatch. Live capability checks belong to
the executing run, before the prompt, with its deadline, terminal failure code
and cleanup. Trace manifests record only type/MIME/size/SHA, excluding bytes and
arbitrary metadata. Model confirmation remains distinct from visual proof.
